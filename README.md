# По чистоте.

Отдельный сайт химчистки мебели в Сочи: `chisto23.ru`.

## Возможности

- калькулятор химчистки по предметам и площади;
- заявка в WhatsApp с готовым составом заказа;
- прайс, примеры «до/после», процесс и FAQ;
- адаптивная версия и SEO-разметка LocalBusiness;
- автоматическая публикация на GitHub Pages из ветки `main`.
- закрытый калькулятор менеджера на `/calc` с выбором города, сметой и Google Calendar.

## Разработка

```bash
pnpm install
pnpm run dev
pnpm run build
```

Контент и цены находятся в `src/App.tsx`, стили — в `src/index.css`.

Внутренний калькулятор находится в `src/internal-calc/`. Серверная функция и
начальная конфигурация Supabase — в `supabase/`. Подключение календаря описано в
[`docs/google-calendar-setup.md`](docs/google-calendar-setup.md).

PIN страницы по умолчанию: `3715`. Это клиентская защита от случайного доступа,
а серверная функция повторно проверяет PIN из секрета `CALC_PIN`.

Рабочий backend калькулятора развёрнут в Supabase-проекте
`apuajxotemukpjheppaz`; Google credentials хранятся только в Edge Function
Secrets и не попадают в клиентскую сборку или Git.

## Постоянные тарифы калькулятора

Шестерёнка в правом верхнем углу `/calc` открывает 49 настроек цен, включая
минимальные заказы, окна, дополнительные услуги и химчистку. Сохранение меняет
только прайс выбранного города в калькуляторе, не цены публичных сайтов.
Копирование заменяет весь прайс города назначения после подтверждения.

Данные сохраняются в закрытой таблице `manager_calc_pricing`: ключ города
соответствует `CITIES` в `supabase/functions/_shared/pricing.ts`. До первого
сохранения город наследует строку `default`. Миграция существующей таблицы не
нужна. Запись выполняется только Edge Function с `service_role`; прямой доступ
`anon`/`authenticated` запрещён. Условная запись по `updated_at` предотвращает
перезапись из устаревшей вкладки.

Перед публикацией интерфейса необходимо установить в Supabase secret
`PRICING_ADMIN_PIN` равным существующему `CALC_PIN` (решение владельца: один PIN)
и обновить функцию `manager-calc`. Значения секретов не хранить в Git.
Если требуется отдельный админ-PIN, сначала добавить отдельный ввод в интерфейс:
сейчас для сохранения используется PIN входа в калькулятор.

```bash
npx supabase login
npx supabase functions deploy manager-calc --project-ref apuajxotemukpjheppaz --no-verify-jwt
npm run test:pricing
npm run build
```

Сервер оставляет старое действие `pricing.get` без города совместимым с прежним
клиентом. Новые действия: `pricing.settings.get` и `pricing.settings.save`.
Тесты тарифов и API выполняются на синтетических данных без записи в production.

Минимальный заказ выбранного вида уборки применяется один раз к общей сумме
уборки, окон, химчистки и дополнительных услуг, если указана площадь уборки.
Стоимость каждой позиции остаётся фактической; доплата до минимума показана
отдельно в расчёте и финансовой смете. Заказ без уборки по площади и пустой
расчёт не получают минимум только из-за выбранной вкладки уборки. Ручная цена
клиента по-прежнему может переопределять итог по прайсу.

## Достижения

Кубок в шапке `/calc` открывает систему достижений «Вершины» в стиле Steam:
восхождение по городам, экспансия, заказы, деньги, рекорды и секретные ачивки.
Расчёт — `supabase/functions/_shared/achievements.ts`, серверное действие
`achievements.get`, экран — `src/internal-calc/Achievements.tsx`.

Все ачивки закрыты, пока после `ACHIEVEMENTS_LAUNCH_AT` не выполнен первый заказ
(событие календаря с «выполнен», «оплачен» или «закрыт» в названии). Этот заказ
открывает всю накопленную историю разом и показывает праздничный экран.

Заказы, «узнавали цену», створки и заметки читаются из календаря. Деньги, реклама
и домены — из таблицы «Вершина деятельность», если она расшарена на service
account (ID зашит в функции, секрет `GOOGLE_SHEET_ID` может его переопределить); иначе деньги считаются по суммам в событиях календаря.

```bash
npx supabase functions deploy manager-calc --project-ref apuajxotemukpjheppaz --no-verify-jwt
npm run test:achievements
```

Ачивки без данных (площадки, команда, офис) отмечаются в `MANUAL_DONE`.

## Командный бот в Telegram

Функция `team-bot` (без проверки JWT на шлюзе) раз в 10 минут проверяет календарь
и присылает в подключённые чаты новые заказы, «узнавали цену», выполнения, отмены
и новые достижения. Чат подключается командой `/start PIN` (PIN калькулятора),
`/ach` — сводка по достижениям, `/stop` — отключить.

Токен бота хранится только в секрете `TELEGRAM_BOT_TOKEN`. После его установки
один раз открыть `https://apuajxotemukpjheppaz.supabase.co/functions/v1/team-bot?setup=1`:
функция сама регистрирует вебхук (секрет вебхука выводится из токена) и команды.
Таблицы и расписание — миграция `20261026000100_team_bot.sql`.
